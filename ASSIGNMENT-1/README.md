
# DBMS Lab Assignment 1

## Overview

This assignment focuses on analyzing and improving **Entity-Relationship (ER) diagrams** by identifying design flaws and introducing the required entities, relationships, and attributes.

## Topics Covered

The assignment contains five ER diagram problems involving:

- **Course and Section Management** — representing course sections, instructors, classrooms, and student enrollment.
- **Hospital Management** — maintaining consultation history, prescriptions, medicines, dosage, frequency, and duration.
- **Order and Shipment Management** — handling order lines, partial shipments, addresses, and shipment details.
- **Employee and Project Management** — tracking employee assignments, roles, work logs, and project managers.
- **Airline Reservation System** — representing PNRs, flight segments, flight occurrences, aircraft assignments, and seat assignments.

## Key Concepts

The diagrams are improved by identifying information that should be modeled separately rather than being stored directly in existing entities. The assignment focuses on maintaining historical information, handling multiple occurrences of the same entity or relationship, and correctly associating attributes with the entities to which they belong.

Each problem includes the identified flaws along with a revised ER diagram addressing those issues.
