# DBMS-LAB-WORKS

A collection of weekly **Database Management Systems (DBMS) laboratory assignments, practical exercises, and solutions** completed throughout the course.

## About

Database Management Systems is an important part of computer science that focuses on how data is **stored, organized, managed, accessed, and maintained efficiently**.

The purpose of the DBMS laboratory is to take the concepts learned in theory and apply them through practical problems. The assignments in this repository are intended to build a better understanding of database design, data modeling, querying, and implementation.

This repository maintains the laboratory work completed throughout the semester in an organized and accessible manner.

## Why DBMS Laboratory Work?

The practical work helps in understanding how database systems are designed and used in real-world applications.

Through these assignments, we learn to:

- Design databases according to given requirements
- Model real-world systems using ER diagrams
- Identify entities, attributes, and relationships
- Understand how data should be structured
- Convert requirements into database designs
- Write and execute SQL queries
- Retrieve and manipulate data efficiently
- Apply constraints and maintain data integrity
- Understand normalization and reduce data redundancy
- Work with different database operations and concepts
- Develop problem-solving skills related to data management

The objective is not only to complete the assignments but also to understand **why a particular database design or operation is required**.

## Topics Covered

The laboratory work may cover topics such as:

- Entity-Relationship (ER) Diagrams
- Entity and Relationship Modeling
- Relational Model
- Schema Design
- Functional Dependencies
- Normalization
- SQL
- DDL and DML Operations
- Constraints
- Joins
- Nested Queries and Subqueries
- Aggregate Functions
- Views
- PL/SQL
- Stored Procedures
- Functions
- Triggers
- Other DBMS practical exercises
